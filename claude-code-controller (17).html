Claude Code Controller v4

DeepSeek tự động cache ngữ cảnh lặp lại phía server (không cần cấu hình thêm), giúp các lượt sau rẻ & nhanh hơn.

Gemini trực tiếp và Proxy trên máy giờ là 2 agent TÁCH RIÊNG hoàn toàn (model, khoá/URL, cấu hình khác nhau). Chọn dùng 1 trong 2, hoặc tick "kết hợp" để cả 2 cùng trả lời mỗi câu lệnh.

🔵 Gemini API — trực tiếp
🟣 Proxy trên máy tôi

Server nhỏ trên máy bạn forward request dạng REST của Gemini (POST <Proxy URL>/v1beta/models/<model>:generateContent hoặc :streamGenerateContent) sang generativelanguage.googleapis.com, hoặc tận dụng phiên đăng nhập/quota Gemini CLI đã đăng nhập sẵn trên máy. Proxy Token (nếu có) gửi kèm header "Authorization: Bearer ...".

Khi tick "kết hợp": mỗi lượt, cả 2 agent (Gemini trực tiếp và Proxy trên máy) đều được gọi song song bằng model/cấu hình riêng của chúng; câu trả lời + các lệnh tool của cả 2 sẽ được gộp lại thành 1 câu trả lời duy nhất (loại trùng tool gọi giống hệt nhau).

PAT cần quyền "repo" (hoặc "contents: write" nếu là fine-grained token). Mọi thông tin chỉ lưu trong localStorage trên máy bạn, không gửi đi đâu khác ngoài GitHub/Anthropic/DeepSeek/FCC. Phiên làm việc (hội thoại + thay đổi tạm) cũng tự lưu theo repo/branch để bạn không mất tiến độ khi tải lại trang.
