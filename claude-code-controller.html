Claude Code Controller v3

DeepSeek tự động cache ngữ cảnh lặp lại phía server (không cần cấu hình thêm), giúp các lượt sau rẻ & nhanh hơn.

Dùng khi bạn chạy 1 proxy cục bộ để "hoà" agent Gemini với máy mình — ví dụ 1 server nhỏ forward request dạng REST của Gemini (POST <Proxy URL>/v1beta/models/<model>:generateContent hoặc :streamGenerateContent) sang generativelanguage.googleapis.com, hoặc tận dụng phiên đăng nhập Google/quota mà bạn đã đăng nhập sẵn trong Gemini CLI (thư mục gemini-cli) trên máy. Cách này giúp giấu khoá API khỏi trình duyệt và vượt giới hạn CORS. Proxy Token (nếu có) sẽ được gửi kèm dạng header "Authorization: Bearer ...".

Model gợi ý: gemini-2.5-pro, gemini-2.5-flash, gemini-3-pro-preview...

PAT cần quyền "repo" (hoặc "contents: write" nếu là fine-grained token). Mọi thông tin chỉ lưu trong localStorage trên máy bạn, không gửi đi đâu khác ngoài GitHub/Anthropic/DeepSeek/FCC. Phiên làm việc (hội thoại + thay đổi tạm) cũng tự lưu theo repo/branch để bạn không mất tiến độ khi tải lại trang.
